# Как выложить игру на GitHub

Репозиторий **уже готов**: ветка `main`, один коммит, `.gitignore` настроен
(папка `.godot/` и архивы в него не попадут). Осталось только отправить его на GitHub.

- файлов в коммите: **197**
- размер папки `.git`: **29 МБ** (включая исходники картинок `art/raw`)
- коммит: `Выживальщик: Арена монстров — состояние на 2026-11-10`

---

## Вариант A. Через сайт GitHub (ничего устанавливать не нужно)

1. Зайти на github.com → **New repository**.
2. Имя, например `survivor-game`, тип Private или Public → **Create repository**.
3. На странице пустого репозитория нажать **uploading an existing file** и перетащить
   туда содержимое папки `my-survivor-game` (кроме `.git` — она не нужна).
4. Внизу — **Commit changes**.

**Если хочется просто скачивать готовый архив** (проще всего):
в репозитории → **Releases** → **Draft a new release** → в поле *Attach binaries*
перетащить `my-survivor-game.zip` (31 МБ) → **Publish release**.
Получится постоянная ссылка на скачивание всего проекта вместе с исходниками картинок.

## Вариант B. Через git (три команды)

```bash
cd путь/к/my-survivor-game
git remote add origin https://github.com/ЛОГИН/survivor-game.git
git push -u origin main
```

Пароль GitHub для push не подходит — нужен **Personal Access Token**
(Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token,
галочка `repo`). В поле пароля вставляется токен.

> Репозиторий создан с одним коммитом, поэтому `push` пройдёт как есть.
> Если на GitHub при создании поставили галочку «Add a README», сначала выполните
> `git pull --rebase origin main`, иначе push попросит `--force`.

## Вариант C. GitHub Desktop

`File → Add local repository` → указать папку `my-survivor-game` → **Publish repository**.

## Что в репозитории

| Папка | Что внутри |
|---|---|
| `scripts/` | вся логика: игрок, враги, снаряды, данные оружия и улучшений |
| `scenes/` | сцены Godot (главная, меню, HUD, эффекты) |
| `art/sprites/` | готовые PNG для игры (герой, враги, эффекты) |
| `art/raw/` | исходники картинок в высоком разрешении (нужны для перегенерации арта) |
| `art/preview/` | превью и GIF для документации |
| `sounds/` | музыка и звуки |
| `docs/`, `README.md` | справочник заклинаний и описание проекта |
| `tools/make_sprites.py` | конвейер обработки спрайтов (хромакей, обрезка, ресайз) |

## Чего в репозитории нет и почему

- `.godot/` — кэш импорта Godot, создаётся заново при первом открытии проекта.
- `*.zip` — архивы (они и так лежат отдельно, например в релизе).
- Настройки пользователя: прогресс, рекорды, золото хранятся вне проекта
  (папка `app_userdata` движка), поэтому в git их нет.

## Как запустить скачанное

1. Установить **Godot 4.7** (версия, на которой собран проект).
2. `Project Manager → Import` → выбрать `project.godot` из папки проекта.
3. Первый импорт занимает минуту: Godot пересоберёт кэш `.godot/`.
4. Нажать **F5**.
