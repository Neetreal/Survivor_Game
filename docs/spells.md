# Заклинания: точные характеристики

Снято из данных игры (`scripts/data/weapon_data.gd`) и `scripts/player.gd` — значения
**первого уровня**, до множителей пассивок. У героя одно заклинание с самого начала,
остальные выпадают в выборе при повышении уровня (новое — каждые 5 уровней), всего **4 слота**.

Стартовые заклинания героев: **Маг** — магические снаряды, **Рыцарь** — клинки на орбите,
**Грозовой маг** — цепная молния, **Друид** — нова.

Поверх всех цифр работают два множителя: **Перчатка** (+урон всего оружия) и
**Свеча** (+площадь и дальность).

---

## 1. Стрелы (`bolt`)

| Параметр | Значение |
|---|---|
| Урон | 12 |
| Стрел за залп | 1 |
| Перезарядка | 0.90 с (минимум 0.25 с) |
| Дальность | 420 |
| Скорость стрелы | 540 |
| Пробитие | 1 враг (карта «Пробитие +1» доводит до 4) |
| Рикошет | 0 (карта «Рикошет +1» доводит до 2, отскок = 70% урона) |

Улучшения: заточка (урон) +25% · скорострельность +20% · +1 стрела · **Пробитие +1** (до 4) ·
**Рикошет +1** (до 2). Карты дальности больше нет — она почти не влияла на игру.

**Две ветки эволюции** (выбор в панели ядра мини-босса, обе можно взять за разные ядра):

| Ветка | Что даёт |
|---|---|
| **Залп** | пробитие **без предела** (все на линии), +2 стрелы, +40% урона, +25% скорости стрелы, шире веер (0.22 рад) |
| **Кара** | **самонаведение** (доворот до 220°/с за ближайшей целью), +60% урона, +1 стрела, −15% перезарядки |

## 2. Клинки на орбите (`orbit`)

| Параметр | Значение |
|---|---|
| Урон | 10 |
| Клинков | 1 |
| Скорость вращения | 2.4 об/с |
| Радиус орбиты | 72 |
| Перезарядка | нет — постоянный урон |

Улучшения: урон +30% · +1 клинок · размер +25% · скорость вращения +25%.

**Эволюция «Вихрь»** (с ядра мини-босса): орбита «дышит» — клинки ходят по спирали, +30% скорости вращения.

## 3. Нова (`nova`)

| Параметр | Значение |
|---|---|
| Урон | 15 |
| Радиус | 140 |
| Перезарядка | 2.50 с (минимум 0.80 с) |

Улучшения: урон +30% · радиус +25% · частота +20%.

**Эволюция «Взрывная волна»** (с ядра мини-босса): нова лечит на 5% нанесённого урона.

## 4. Цепная молния (`chain`)

| Параметр | Значение |
|---|---|
| Урон | 18 |
| Перескоков | 3 (плюс первая цель) |
| Перезарядка | 1.80 с (минимум 0.60 с) |
| Дальность первой цели | 320 |
| Дальность перескока | 180 |

Улучшения: урон +30% · частота +20% · +1 перескок · дальность +25%.

**Эволюция «Гроза»** (с ядра мини-босса): +3 перескока, молния достаёт до всех врагов на экране.

## 5. Огненный шар (`fireball`)

| Параметр | Значение |
|---|---|
| Урон | 20 |
| Шаров за залп | 1 |
| Радиус взрыва | 75 |
| Перезарядка | 1.40 с (минимум 0.50 с) |

Улучшения: урон +30% · частота +20% · +1 шар · радиус взрыва +25%.

**Эволюция «Метеор»** (с ядра мини-босса): взрыв в 1.8 раза шире и на 40% сильнее.

Стартовое заклинание **огненного мага** (`fire`, 75 HP, скорость 240).

## 6. Ледяная аура (`frost`)

| Параметр | Значение |
|---|---|
| Урон | 3 за тик, тик каждые 0.5 с (=6/с) |
| Радиус | 130 |
| Замедление | 50% (враг идёт вдвое медленнее) |
| Перезарядка | нет — постоянная аура |

Улучшения: урон +50% · радиус +25% · замедление +8% за уровень (максимум 75%).

**Эволюция «Заморозка»** (с ядра мини-босса): замороженный враг разбивается — урон ×3 в радиусе 110.

## 7. Бумеранг (`boomerang`)

| Бумерангов за бросок | 1 |
| Дальность вылета | 210 |
| Перезарядка | 1.60 с (минимум 0.60 с) |

Улучшения: урон +30% · частота +20% · +1 бумеранг.

**Эволюция «Пила»** (с ядра мини-босса): +2 бумеранга, летят сквозь врагов.

## 9. Мины (`mine`)

|---|---|
